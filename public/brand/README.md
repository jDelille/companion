# Kiosk crest

`uft-crest.jpg` is an unchanged copy of
`addons/dojo_kiosk/static/src/img/uft-logo.png` from this repository.
The source file contains JPEG bytes despite its PNG suffix.

United Family Taekwondo is the school identity; Dojang Companion remains the
application name. The image is rendered as decorative background branding with
CSS edge feathering and low opacity, with the original colors preserved. The
source image bytes are unchanged; no replacement or generated logo is used.
